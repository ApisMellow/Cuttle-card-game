# Cuttle

A Go implementation of the two-player card game [Cuttle](RULES.md): a pure rules engine, a text renderer, and a hot-seat REPL where every menu option is a legal move generated by the engine.

## Layout

- `card/` — suits, ranks, cards
- `engine/` — immutable `GameState`, `LegalMoves`, `Apply`
- `render/` — pure text formatter
- `cmd/cuttle/` — hot-seat REPL
- `RULES.md` — authoritative rules
- `docs/plans/` — implementation plan

## Requirements

- Go (stdlib only, no external deps)

## Testing

Run from the repo root.

```sh
go test ./...               # all packages
go test -v ./...            # verbose
go test ./engine/           # one package
go test ./engine/ -run TestScenario_JackChainSteal   # one test
go vet ./...                # static checks
gofmt -l .                  # formatting (no output = clean)
```

## Playing the REPL

```sh
go run ./cmd/cuttle
```

Or build a binary:

```sh
go build -o cuttle ./cmd/cuttle
./cuttle
```

### How it plays

- Hot-seat: both players share the terminal. No hidden hands — pass the keyboard.
- Each turn the REPL prints the full game state, then a numbered menu of every legal move generated by the engine.
- Type the number of the move you want and press enter.
- The engine enforces all rules — anything that isn't on the menu isn't legal.
- First player to 21 points, or on a declining scale with Kings in play, wins.

See [RULES.md](RULES.md) for the full rules, including one-offs, counters, Jack steals, and Queen protection.
